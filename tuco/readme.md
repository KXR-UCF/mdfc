## TUCO:
Tuco is a large, single sided (except the teensy), 2 layer (ideally) mainboard with test connectors for all the signals coming from the teensy. It acts as an exploded version of Heisenberg, so the software can be bench tested, the power supplies can be stress tested and analyzed, and signal issues can be troubleshooted.

It is designed to fit onto a standard breadboard with the 40 pin header for the module connectors, and the 10 pin header using an extender cable for the servo connector. It has high current screw terminals on the power rails for stress testing the power module, or externally powering the board for testing. It also has larger free space for indicator LEDs or test points to be added at a later date.
